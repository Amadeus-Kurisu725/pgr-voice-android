# 界面设计 · 第三版「战术 HUD / 全息终端」

目标：让应用在气质上接近战双帕弥什的工业后启示录界面——近黑分层灰、切角面板、细线框、HUD 分隔与角标、
单一深红强调色——同时完全不使用任何官方美术、截图、标志或游戏衍生素材。所有装饰均由原生 Canvas 代码绘制，
字体只用系统字体。上一版的 AI 生成封面 `Assets/ui/story-archive-v2.png` 已移除（不再随 APK 提供）。

## 设计系统（唯一来源）

| 位置 | 内容 |
| --- | --- |
| `Ui/PgrTheme.cs` | 颜色、字号、间距、切角尺寸等全部令牌；按钮、卡片、标签页、输入框、开关、单选、进度条、对话框、列表适配器的统一样式函数 |

### 字体与排版

系统 `sans-serif`（中文由系统 CJK 字体回退）、`sans-serif-medium`、`sans-serif-condensed`（英文小标签）、
`monospace`（编号、进度、路径）；数字启用 `tnum` 等宽数字。字号阶梯 26/21/17/15/13/12/11/10 sp。
中文标题旁配小号大写英文副标签（如「剧情 / STORY」），只作装饰，不替代原中文含义。

### 融合方向（红色战术 HUD × 青色全息数据层）

- 红色 = 身份 / 操作 / 正在播放：主按钮、选中项、当前台词卡、听书正在播放卡、频谱已播放部分、分段进度、标签指示条、准星中心点，均带霓虹辉光。
- 青色 = 数据 / 读数 / 次要状态：时间码、序号、坐标与十六进制读数、信号条、数据流状态条、细弧仪表、角标、网格点阵、玻璃内高光、扫描线。
- 两种颜色各司其职，不混用在同一类元素上，避免杂乱。

### 科幻 / 全息层

- 霓虹辉光：主按钮、选中卡片、标签指示条、信号条、分隔线红色刻度带发光（静态绘制）。主按钮面板在视图内缩 2dp，辉光留在视图裁剪内，触控区仍 ≥ 48dp。
- 玻璃层：卡片与悬浮层顶部冷色光泽渐变；对话框、当前台词卡带扫描线与顶边缺口（notched frame）。
- 主界面标题下有一条数据流状态条（青色等宽字 + 信号格，纯装饰），横屏紧凑模式隐藏。
- 页面底纹：极淡网格 + 网格交点青色点阵 + CRT 扫描线 + 静态斜向扫光带 + 右上准星 + 左侧刻度尺 + 竖排坐标 / 十六进制读数（纯装饰，不是数据）。
- 主视觉：青色弧形仪表与刻度环、发光红色弧段、分段数据条、十六进制读数、红/青色差错位的轮廓数字。
- 标题：Display/Title 角色带 1.2dp 红色错位“故障”残影（文字阴影，静态，不影响正文对比度）。
- 进度：SeekBar / ProgressBar 统一为分段全息条（青色暗格 + 发光红格）。听书当前句上方有频谱式进度条：柱高按句子 ID 固定生成，只随真实播放位置点亮，不是实时音量表。
- 不加持续动画；悬浮层只用静态辉光与光泽，不加扫描线，保持轻量。

### 形状与状态

- 卡片：左上 + 右下切角；按钮：右下切角；主按钮：对角切角 + 斜纹；选中：深红底 + 左侧红色信号条 + HUD 角标。
- 禁用：降低填充与文字对比，但仍可辨认；按下：红色或白色波纹裁剪到切角形状。
- 触控目标最小 48dp（应用内）。悬浮层沿用原有尺寸，避免改变点击判定区域。
- 动画只保留系统波纹，不加持续装饰动画。

## 悬浮层约束

悬浮层只换外观（半透明玻璃面板、红色信号条、细线），不改窗口大小、位置计算和排除带；
分支识别框的细青色线保持原样（它位于 OCR 文字矩形之外，刻意避免把提示文字或底色送进 OCR）。

### 角色立绘与原创装饰（不含任何游戏素材）

- 说话人头像：当前台词卡（48dp，横屏 34dp）、听书正在播放卡（64dp，带序列号 + 呼号行）、悬浮台词条（30dp）。切角框 + 红色辉光描边 + 青色角标 + 扫描线 + 底部暗角。图片只从应用自身文件夹读取：`Android/data/cn.pgrvoice.player/files/portraits/<角色名>.png|jpg|webp`；设置页“导入角色头像”可从系统文件选择器复制图片到该文件夹（文件名即角色名）。缺图时显示原创几何字标（六边形框 + 红色斜切 + 名字首字），旁白显示原创徽记。
- 背景立绘（可在设置页“背景立绘：显示/隐藏”切换，默认显示，仅在有图片时生效）：`files/standees/<角色名>.*`，只用于听书正在播放卡，靠右放置，峰值不透明度 25%，向左与向下渐隐，保证正文 AA 对比度。悬浮窗不画立绘，保持轻量。
- 解码在后台线程按尺寸降采样（头像 ≤96dp、立绘 ≤420dp），内存 LRU 缓存 24 项；不随应用打包、不联网下载任何图片。
- 原创装饰：构造体序列号（CN-XXXX，按名字哈希生成）、小队呼号（STRIX / KESTREL / HALCYON / TALON / SHRIKE / MERLIN + 数字，原创词）、数据流状态条中的“SQD STRIX-07”呼号框、红色像素“侵蚀”边缘纹理（主视觉卡底边、页面左下角）、原创轨道空间站徽记（分割圆环 + 倾斜轨道 + 六边形核心 + 红色尖塔 + 三道 V 形，非官方标志）。
