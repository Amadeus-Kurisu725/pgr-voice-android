# 听书 / 游戏互斥与历史试听回归

运行 `python android/Tests/AudioModeRegression/run.py --output <生产目录外的本轮报告目录>`。
可加 `--source-root <历史源码快照>`，用同一测试验证旧版本确实失败。报告目录必须明确提供，产物、临时存档与构建输出均留在该目录；不操作设备、不写正式配音库。

测试直接编译真实 `ListeningSession`、`ListeningForegroundService`、`AppSession.Playback`、共享核心及其全部内嵌资源。运行器每次从所选源码完整抽取六个游戏入口、`PrepareListening`、`StopGame`，记录源码哈希和听书 `beforePlay` 接线。其余六个游戏入口核对互斥调用。Android 时钟、服务、通知、音频及窗口为受控替身，因此结果不等于设备解码或实际焦点验证。

覆盖：倒计时切到游戏后的互斥、迟到计时回调、重复暂停与明确继续保留剩余秒数；历史试听命中原配时仍播放配音；正常游戏原配仍静音且不申请焦点；关闭原配与按章覆盖；取消 / 换章 / 新请求后的迟到播放回调。原配身份由所测源码的真实内嵌目录生成最小元数据，使用临时文件并以受控音频验证调用与音量，不使用正式音频。
